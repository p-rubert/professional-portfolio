Excel VBA Warehouse Location Audit Automation

An Excel VBA-supported warehouse location audit workflow combining barcode scans, two-operator scan stations, ERP verification, color-coded results, first-match location-and-part lookup, and audit tracking.

Microsoft ExcelVBABarcode scanningInventory control

Project Overview

Developed and implemented a Microsoft Excel VBA-based warehouse location auditing system used for recurring inventory audits every two months. The completed workbook supports barcode scanning through two operator input stations, verifies scanned part numbers against ERP location records, and provides automated discrepancy identification, color-coded results, and user/timestamp tracking. The system operates within an Excel macro-enabled workbook and supports a standardized, repeatable warehouse auditing workflow.

Problem Statement

Warehouse location auditing requires verifying that physical inventory is stored in the correct locations according to ERP records. Manually comparing scanned part numbers and warehouse locations against inventory records can involve repetitive searching and make discrepancies more difficult to document consistently. The project addressed these workflow challenges by automating location-and-part verification, visually distinguishing matching records from discrepancies, and recording audit activity for follow-up and review.

Project Objectives

  • Support barcode-based scanning at two-operator scan stations.
  • Verify scanned audit information against ERP records.
  • Make audit results easier to distinguish with color coding.
  • Record audit activity with user and timestamp tracking.
