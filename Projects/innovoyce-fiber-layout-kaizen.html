Innovoyce Fiber Cell Layout Improvement

Completed team Kaizen project to improve the Innovoyce fiber manufacturing cell and gowning-area layout. I participated in the Kaizen process and physically helped rearrange and correct the layout to improve workstation organization, production flow, and contamination controls.

KaizenCell layoutProcess flowParticulate testing

Project Overview

I participated in the team Kaizen and physically helped implement corrections to the Innovoyce fiber manufacturing cell layout. The work included evaluating the existing layout, identifying wasted motion and process inefficiencies, and supporting improvements to workstation organization, production flow, and gowning-area contamination controls.

Problem Statement

The original manufacturing cell and gowning-area layout created excessive operator motion, inefficient workflow, contamination risks, rework, and reduced throughput.

Project Objectives

  • Evaluate the existing cell layout and identify wasted motion and process inefficiencies.
  • Participate in the team Kaizen improvement process.
  • Physically help rearrange and correct the manufacturing cell layout.
  • Support improved workstation organization, production flow, and gowning-area contamination controls.

Business Impact & Skills Demonstrated

The project report identifies reduced motion, improved cleanliness, reduced defects, and reduced rework as benefits. Particulate testing improved compared with the historical average after air-conditioning installation and layout changes; the improvement is not attributed to layout changes alone. Final defect data was pending review, so no quantified or statistically verified defect improvement is claimed.
